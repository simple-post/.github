# SimplePost

SimplePost is a free, open-source posting stack for AI agents, apps, scripts, and humans.

Use one TypeScript-powered layer to validate, preview, publish, and schedule social posts across platforms, then choose the interface that fits your workflow:

- **MCP server** for ChatGPT, Claude, Cursor, and other AI clients
- **TypeScript SDK** for apps and agents
- **HTTP API** for backend services and integrations
- **CLI** for terminal workflows, scripts, CI, and local agents
- **Scheduler app** for writing, previewing, posting, and scheduling from a web UI

SimplePost is built for ownership: self-host it, inspect the code, connect your own social platform apps and credentials, and adapt it to your stack.

Supported platforms include X, Telegram, Instagram, Facebook, Threads, TikTok, YouTube, Pinterest, LinkedIn, and Bluesky.

The developer platform is coming soon at [simplepost.dev](https://simplepost.dev).

If you want the hosted product today, use the AI-native scheduling app and hosted API at [simplepost.social](https://simplepost.social).
